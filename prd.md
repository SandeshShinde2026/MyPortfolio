📄 PRODUCT REQUIREMENTS DOCUMENT (PRD)
Product Name: Mobile Developer Portfolio (iOS-style Experience)

🎯 1. Objective
Build a premium portfolio website that:


Feels like an Apple product page


Showcases mobile apps as finished products


Uses minimal color, strong typography, and smooth motion


Creates trust instantly



👤 2. Target Users
Primary:


Recruiters (tech companies)


Startup founders


Clients (freelance)


Their expectation:

“This developer builds clean, high-quality apps.”


🧠 3. Core Experience Principles
1. Minimalism > Decoration


No gradients


No loud colors


Lots of whitespace


2. Motion = Meaning


Every animation should feel intentional


Smooth, not flashy


3. Product-first storytelling


Apps should feel like App Store features



🎨 4. Design System (CRITICAL)
Color Palette (No Gradients)
Base:


Background: #0A0A0A (deep black)


Surface: #111111


Border: #1C1C1E (iOS-like)


Text:


Primary: #FFFFFF


Secondary: #A1A1AA


Accent (VERY LIMITED USE):


Soft blue or white highlight (like iOS buttons)


👉 No neon, no purple gradients.

Typography
Use Apple-style hierarchy:


Headings: SF Pro Display / Inter


Body: Inter


Sizes:


Hero: 48–64px


Section titles: 28–36px


Body: 16–18px



UI Style


Rounded corners (16–24px)


Soft shadows


Thin borders


Glass effect (very subtle blur)

⚡ 6. Motion & Interaction Design
This is where your site becomes “premium”.

Scroll Behavior


Smooth scrolling (important)


Sections fade in (not pop)


No sudden transitions



Animation Rules


Duration: 300–600ms


Easing: ease-in-out


Avoid bounce effects



Key Effects


Parallax (very subtle)


Fade + translateY


Hover micro-interactions



⚙️ 7. Tech Stack

Styling: Tailwind CSS


Animations: Framer Motion


Hosting: Vercel
